## 一分钟看懂这个项目

**问题**：小佩（PETKIT）在 B站 的内容生态里处于什么位置？内容资源该往哪投？

**做法**：

```
B站 35 个关键词 × 10 页  →  8,792 行原始数据（含一次补采）
        ↓ 清洗去重剔噪
     4,375 条有效样本 / 3,039 位创作者
        ↓ 弱监督：19 条可弃权的标注函数 + 大模型标注 + 自一致性投票
        ↓ 人工抽检验证（分层随机 200 + 主动学习 100）
     标注准确率 88.0%（Wilson 95%CI 82.8%~91.8%）
        ↓ 五路分析（产品线 / 品牌声量 / 用户痛点 / 内容策略 / 使用场景）
     运营方案 + 交互式看板 + 运营问数 Agent
```

**主要发现**：

- **猫砂盆是声量基本盘**（560 条，占 A 级 41%），但互动效率被饮水机 / 喂食器 / 摄像头反超；
  **净化器、摄像头属于"高播放、低供给"**，是内容机会点。
- **小佩声量第一**（提及 301 次、横评份额 30.6%），但**互动率 1.37% 低于霍曼 2.15%、小米 2.27%**；
  官方内容"高播放低互动"（播放中位 10,874 / 互动率 0.83%），达人内容反之（1,370 / 1.56%）。
- **异味/除臭是猫砂盆最高频痛点**（160 条），但播放中位数仅 1,131，
  远低于价格痛点 6,476 —— 说明**痛点表达方式效率低**。
- **DIY/改装（互动率 3.93%）和 >10min 长视频（3.46%）效率最高，开箱/上手最低（1.59%）**。

## 方法上值得说的三点

1. **弱监督 + 可弃权规则**：19 条标注函数按 `λ: X → Y ∪ {-1}` 设计，
   有把握才投票、没把握就弃权；再统计每条规则的 coverage 与**实测精度**。
2. **人工验证设计**：**分层随机 200 条用于"度量"准确率，主动学习 100 条用于"发现错误"**，
   两者严格分开——用主动学习样本算准确率是系统性错误，不是"有误差"。
3. **量化了金标准本身的噪声**：对 34 条"模型与人工分歧"的样本做**二轮盲判复核**
   （不给模型答案），发现**人工自洽率仅 38.2%**，据此给出真实准确率区间 `[88.0%, 93.5%]`。

> 项目还诚实记录了**两次自我纠错**：
> 一是规则层有个"猫砂盆"被当成"猫砂"的子串 bug，让耗材规则 59% 的投票是假阳性，
> 修复后规则聚合准确率从 87.5% 升到 88.5%——但**仍然追不上大模型单独判定**，
> 因此最终标签改用大模型，规则层降级为可解释性报告；
> 二是发现采集脚本被 B站 限流中断却没记录原因，于是**补采**了 13 个未采满的关键词，
> 有效样本从 3,747 条增加到 4,375 条。详见 `docs/方法使用规范.md` 第六节。

```powershell
run_eval.bat

# 3) 五路分析 + 交付物
python src\py\analyze.py
python src\py\gen_report.py
python src\py\make_dashboard.py
```

## ⚠️ 已知局限

- 数据来自 **35 个关键词的搜索结果，不是随机抽样**，只能做**相对比较**，
  不能做绝对市场规模 / 份额判断。
- 标注准确率 **88.0%**（95%CI 82.8%~91.8%），存在约 12% 误标空间；
  人工标注为**单一标注者、无重复核验**。
- 鱼缸（n=9）、摄像头（n=39）等小样本品类指标波动大，仅作参考。
- 详细局限见 `docs/项目说明书.docx` 第五节。
