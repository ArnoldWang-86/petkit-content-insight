# 人工核对速查卡（A / B / C / N）

> 填 `results/人工抽检_300条_方案B.csv` 时对照本卡，保证 300 条标准一致。

---

## 一句话区分

| 标签 | 含义 | 一句话判断 |
|---|---|---|
| **A** | 直接相关 | **内容主体就是宠物智能硬件产品本身** |
| **B** | 延伸相关 | **不是硬件，但会影响买不买硬件** |
| **C** | 用户语境 | **理解养宠的人是谁、在意什么** |
| **N** | 非宠物 | **跟宠物完全没关系** |

---

## 详细定义与例子

### A 直接相关 —— 宠物智能硬件产品本身

**内容主体是**：智能猫砂盆、宠物饮水机、自动喂食器、宠物空气净化器、智能鱼缸、
宠物摄像头、烘干箱、加热垫/智能猫窝 等**智能设备**的
测评 / 横评 / 开箱 / 使用教程 / 官方发布 / 硬件DIY

**例子**
- 「2026年智能猫砂盆推荐｜10款大横评｜小佩/CATLINK/霍曼」
- 「米家宠物饮水机2开箱体验」
- 「STM32智能宠物喂食系统」
- 「自制猫咪烘干箱」（DIY 硬件，也算 A）

**关键**：必须是**智能/自动/可联网/可远程**的设备。
「猫砂盆怎么选？开放式还是封闭式」——这是**普通猫砂盆**，不是 A，是 B。

---

### B 延伸相关 —— 不是硬件，但影响产品决策

**两类**
1. **耗材与日用品**：猫砂、猫粮、罐头、猫条、冻干、猫抓板、猫爬架、洗护用品
2. **非智能硬件选购**：宠物定位器、普通猫窝、狗粮等

> ⚠️ **2026-10-06 修订：健康医疗已从 B 移到 C**（依据「标签体系修订记录v2.md」修订项 1）。
> 疾病、治疗、用药、体检、医院 → 一律给 **C**，不给 B。

**例子**
- 「4款猫砂一起试，一捏就化和整块拿起差太多」
- 「实测24款宠物定位器，最终只推荐这4款」

**为什么算相关**：猫砂选得好不好 → 影响智能猫砂盆是否好用；
猫的泌尿问题 → 直接影响宠物饮水机的卖点（该内容本身按 C 标，但它是产品卖点的来源）。

---

### C 用户语境 —— 理解用户是谁、在意什么

**内容类型**：**疾病健康（2026-10-06 由 B 移入）**、养护科普、日常vlog、萌宠搞笑、领养救助、猫舍

**例子**
- 「【论文养猫1】全网最专业猫癣治疗指南」（疾病健康 → C）
- 「6个养猫常见的踩坑问题」
- 「猫：我干了，放我出去！」
- 「两只流浪狗第一次当奶爸」

**为什么算相关**：做内容运营要知道用户在看什么、在意什么，
这类内容是**用户真实语境的来源**，但不涉及具体产品决策。

---

### N 非宠物 —— 与宠物无关

**是搜索噪声**：家电、母婴、游戏、食品、数码3C

**例子**
- 「【2026无线洗车机推荐】12款便携高压水枪测评」（被"饮水机"捞进来）
- 「小甜水？瑞幸咖啡新品」（被"宠物饮水机"捞进来）
- 「我的世界投喂机器教程」（被"自动喂食器"捞进来）
- 「宝宝喂养台怎么选」（被"猫砂盆"捞进来）

## 七条判断原则（容易错的地方）

1. **只看标题和标签**，不要脑补视频内容
2. **「有硬件词」≠ 智能硬件**：普通猫砂盆、普通猫窝 → **B，不是 A**
3. **「有宠物词」≠ 宠物硬件**：猫粮测评 → **B，不是 A**
4. **健康医疗 → C**：猫癣、尿闭、疫苗、用药、体检、医院等 → **C，不是 B**（2026-10-06 修订）
5. **通用品牌要看语境**：小米/米家/美的 必须同时有宠物语境才算宠物内容
6. **子串陷阱**：「鸟语花香」是**品牌名**不是鸟；「猫眼」不是猫；「熊猫」不是猫；
   还有 **「猫砂盆」不是「猫砂」**（智能硬件与耗材要分开看）
7. **拿不准时**：宁可给 B 或 C，**不要轻易给 A**

## 快速判断流程

```
标题里有"猫/狗/宠物"或明显宠物内容吗？
 ├─ 没有 → N（非宠物）
 └─ 有 ↓
     主体是"智能/自动/可联网"的宠物设备吗？
      ├─ 是 → A
      └─ 否 ↓
          是耗材/日用品/非智能用品选购吗？
           ├─ 是 → B
           └─ 否 → C（疾病健康、养护、日常、萌宠、领养）
```
