## 五、未处理的问题（如实记录）

1. **`docs/项目交接文档.docx` 未能重新生成**：清理时发现该文件正被 Word（进程 WINWORD，PID 3028）打开，
   写入被拒绝（PermissionError）。它的 `.md` 源文件本轮**没有改动**，因此现有 docx 与 md 内容仍然一致，
   **不影响交付**。同样原因，`docs/~$项目交接文档.docx` 这个 Word 锁文件保留到 Word 关闭后由系统清除。
2. **`__pycache__` 会随运行重建**：这是 Python 的正常行为，已加入 .gitignore，不会进入仓库。
