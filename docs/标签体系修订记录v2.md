# 标签体系修订记录（v2）

> 本记录说明本轮对标签定义做了哪些修改、为什么改、依据是什么。
> 所有修改都来自**实际数据暴露的问题**，不是主观调整。

---

## 一、修订清单（共 6 项）

| # | 修改 | 触发原因 | 依据 |
|---|---|---|---|
| 1 | **健康医疗：B → C** | 实测 170 条健康内容中 65% 被模型判为 C，与规则层的 B **互相矛盾** | 用户决策（方案A） |
| 2 | **补产品线：净化器、鱼缸** | 这两类内容被归到"其他/泛宠物"，实际有大量内容 | 数据：小佩起源纪智能鱼缸、霍曼宠物净化器 |
| 3 | **加热垫/猫窝：移出智能硬件 → B** | 非智能品类，品牌竞争极弱 | 数据：154 条中仅 3 条提及品牌 |
| 4 | **摄像头：保留 A** | 有专业横评，是独立宠物品类 | 数据：165 条中有宠物摄像头专项横评 |
| 5 | **新增内容形态「使用体验/吐槽」** | 与"横评/测评"混在一起，但运营价值不同 | 购买前看测评、购买后看吐槽 |
| 6 | **新增「天生即智能」品类** | 净化器/烘干箱/鱼缸标题通常不写"智能"，导致误判为 B | 实测：152 条烘干箱中 84% 标题无"智能"二字 |

## 二、两个最重要的概念修正

### 修正1：判断依据从「品类是否智能」改为「是否品牌竞争型硬件」

**旧标准**（错误）：品类本身是否智能
**问题**：烘干箱横跨 300 元普通款 与 3000 元智能款，无法一刀切

**新标准**（正确）：
> **该品类是否有多个品牌在做、按功能参数竞争、有专业横评**

| 品类 | 品牌竞争 | 归级 |
|---|---|---|
| 猫砂盆 | 小佩144 / CATLINK140 / 霍曼37 | **A** |
| 饮水机 | 小佩58 / 小米27 / 霍曼17 | **A** |
| 喂食器 | 小佩43 / 小米38 / 霍曼32 | **A** |
| 烘干箱 | 霍曼40 / 小佩18 / 鸟语花香7 | **A** |
| 摄像头 | 有专项横评 | **A** |
| 净化器 / 鱼缸 | 霍曼、米家、美的 | **A** |
| **加热垫/猫窝** | **仅 3 条提品牌** | **B** |

### 修正2：必须区分「产品是主体」还是「宠物是主体」

这是本轮最关键的修正。同一句话里的产品，可能是主角，也可能只是道具：

| 内容 | 主体 | 标签 |
|---|---|---|
| 猫咪玩饮水机，洗脚水自己喝 | **猫咪的行为** | **C** |
| 宠物饮水机这么多怎么选 | **产品本身** | **A** |
| 酸奶机做恒温饮水机～猫咪日常 | **猫咪日常** | **C** |
| 自动猫砂盆是"真香"还是"踩坑" | **产品本身** | **A** |

**实现方式**：新增两组信号词
- **产品导向信号**：测评、横评、推荐、怎么选、开箱、避坑、优缺点…
- **宠物行为信号**：玩、搞笑、可爱、日常、记录、反应、萌…

当"宠物行为"强于"产品导向"时，规则层**不投 B**，改由 C 规则接管。

## 三、修订后的标签体系

### 相关性四级

| 级别 | 定义 | 包含 |
|---|---|---|
| **A 直接相关** | 品牌竞争型宠物智能硬件**产品本身** | 猫砂盆/饮水机/喂食器/摄像头/烘干箱/净化器/鱼缸 的测评、横评、开箱、教程、吐槽 |
| **B 延伸相关** | 影响"买哪款硬件"的决策 | 耗材（猫砂猫粮）、**非智能用品**（加热垫/猫窝/猫抓板）、非智能硬件选购 |
| **C 用户语境** | 理解养宠的人 | **疾病健康**、养护科普、日常vlog、领养救助 |
| **N 非宠物** | 与宠物无关 | 家电、母婴、游戏、**通用安防**、食品、数码 |

### 产品线（7 类）
猫砂盆 / 饮水机 / 喂食器 / 摄像头 / 烘干箱 / 净化器 / 鱼缸

### 内容形态（6 类）
使用体验/吐槽 / 横评选购 / 教程指南 / 开箱上手 / DIY改装 / 闲置二手

## 五、已知局限（将写入抽检报告）

1. **规则层无法完全替代语义理解**：虽然新增了主体检测信号，但极端表述仍可能误判。
   这类错误正是人工抽检要量化的对象。
2. **"天生即智能"清单需人工维护**：新产品形态出现时要手动补充。
3. **健康与养护的边界仍有模糊**：两者都归 C 后边界清晰了，但个别内容（如"猫咪频繁进出猫砂盆"）
   可能同时涉及健康与硬件。
